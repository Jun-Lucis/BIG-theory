# BIG-B28 — Geometry-Conditioned Response-Lineage Transport

B28 begins after the formal closeout of B27.

B27 established that retained readable history can change local response geometry, but the simplest topology-reconfiguration invariance hypothesis failed prospectively. B28 therefore asks a different question: whether the **transformation** of history-induced response structure can be predicted from reconfiguration geometry.

The primary architecture is a **component-resolved 1-to-2 split transport**:

\[
\mathbb R^5
\longrightarrow
\mathbb R^5\oplus\mathbb R^5.
\]

A geometry-only split operator \(S_\Gamma\) maps the pre probe space into two child-local post probe spaces. The post response is then pulled back to the original five-dimensional probe space before history-induced response-lineage forms are compared.
